nix-purifiers

A purifier is a plugin and a Nix library for a build tool. It records the files the build tool wants to download in a lockfile, or reuses the tool's existing lockfile, so that Nix can build the project in its sandbox. Unlike many existing tools, purifiers do not require you to commit generated Nix files to your repository.
